## 1. Platform Overview

Microsoft Azure is Microsoft's cloud computing platform. It provides services for computing, storage, networking, databases, security, analytics, application development, and artificial intelligence. Azure is especially useful for organizations that already depend on Microsoft products and technologies.

## 2. Global Infrastructure

Azure uses a worldwide infrastructure made up of geographic regions and availability zones. Organizations can choose locations according to their performance, availability, compliance, and data residency requirements.

## 3. Cloud Management Console

The Azure Portal is Microsoft's web-based management interface for cloud resources. From the portal, users can create and manage virtual machines, storage accounts, databases, networks, applications, and other Azure services.

## 4. Four Core Services

### Azure Virtual Machines

Azure Virtual Machines provide virtualized computing environments for Windows and Linux workloads.

### Azure Blob Storage

Azure Blob Storage is designed to store large amounts of unstructured data such as images, videos, documents, and backups.

### Azure Virtual Network

Azure Virtual Network allows Azure resources to communicate within a controlled and secure networking environment.

### Microsoft Entra ID

Microsoft Entra ID provides identity and access management for users, applications, and organizational resources.

## 5. Three Advantages

1. Azure works closely with Microsoft's enterprise technologies.
2. It supports both cloud and hybrid infrastructure environments.
3. Azure provides many services for application development, security, databases, analytics, and AI.

## 6. Typical Enterprise Use Cases

Azure is commonly suitable for:

- Windows Server migration
- Microsoft-based enterprise applications
- Hybrid cloud environments
- Business applications
- Database hosting
- Virtual desktops
- Identity management
- AI and analytics
- Enterprise application development
