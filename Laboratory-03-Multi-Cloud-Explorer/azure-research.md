# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform that provides cloud services for computing, storage, networking, databases, and other technologies. It helps organizations build, deploy, and manage applications and services through Microsoft's cloud infrastructure.

## Global Infrastructure

Azure provides a global cloud infrastructure consisting of geographic regions and data centers. Its infrastructure is designed to provide availability, reliability, and access to cloud services in different parts of the world.

## Cloud Management Console

The Azure portal is a web-based management interface used to create, configure, monitor, and manage Azure resources and services.

## Four Core Services

1. **Azure Virtual Machines** – Provides virtualized computing resources for running applications and workloads.
2. **Azure Blob Storage** – Provides scalable object storage for unstructured data.
3. **Azure Virtual Network** – Provides networking capabilities for Azure resources.
4. **Microsoft Entra ID** – Provides identity and access management for users and applications.

## Three Advantages

1. **Microsoft integration** – Azure works closely with Microsoft technologies and services.
2. **Scalability** – Resources can be adjusted based on workload requirements.
3. **Enterprise capabilities** – Azure provides services designed for organizations with complex IT environments.

## Typical Enterprise Use Cases

Azure can be used for enterprise applications, Windows Server workloads, Microsoft 365-related environments, databases, virtual machines, application development, and hybrid cloud solutions.
