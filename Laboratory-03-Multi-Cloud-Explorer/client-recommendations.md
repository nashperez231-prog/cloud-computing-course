## Client A – Startup Company

### Recommended Platform: AWS

AWS would be a practical choice for the startup because it provides many services that can support an application from its early development stage to large-scale deployment. The company can begin with a smaller infrastructure setup and increase resources as the number of users grows. Managed services can also reduce the amount of infrastructure that the startup has to maintain.

### Suggested Services

- Amazon EC2
- Amazon S3
- Amazon RDS
- Amazon CloudFront

---

## Client B – University

### Recommended Platform: Microsoft Azure

Azure is the strongest match for the university because its existing environment already depends on Windows Server, Microsoft 365, and Active Directory. Moving selected workloads to Azure can allow the university to continue using Microsoft-based identity and management technologies. This can also make a gradual cloud migration easier to manage.

### Suggested Services

- Azure Virtual Machines
- Microsoft Entra ID
- Azure SQL Database
- Azure Virtual Network

---

## Client C – AI Research Company

### Recommended Platform: Google Cloud Platform

Google Cloud would be a suitable choice for the research company because its platform provides strong tools for artificial intelligence and machine learning. The company can combine computing resources with managed AI services and scalable data storage. Kubernetes support can also help the research team deploy containerized workloads.

### Suggested Services

- Compute Engine
- Vertex AI
- Google Kubernetes Engine
- Cloud Storage

---

## Client D – Global E-Commerce Company

### Recommended Platform: AWS

AWS is a strong option for a worldwide e-commerce company because it provides services for scalable and highly available applications. The company can distribute workloads across infrastructure locations and use load balancing and automatic scaling to respond to changing customer traffic. Content delivery services can also help improve the experience of customers in different geographic areas.

### Suggested Services

- Amazon EC2
- Elastic Load Balancing
- Amazon EC2 Auto Scaling
- Amazon CloudFront
- Amazon S3

---

# Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| Startup Company | AWS | Flexible services and scalable infrastructure can support growth. |
| Enterprise Organization | AWS | Large service selection and global infrastructure support complex workloads. |
| Microsoft Environment | Azure | Strong compatibility with Microsoft products and identity technologies. |
| AI / Machine Learning | GCP | Strong AI, ML, data, and specialized computing capabilities. |
| Kubernetes Deployment | GCP | Google provides Google Kubernetes Engine and strong cloud-native tooling. |
| Global Web Application | AWS | Global infrastructure combined with load balancing, scaling, and content delivery services. |

## Final Recommendation

The appropriate cloud provider depends on the actual requirements of the organization. AWS is a strong general-purpose option, Azure is particularly suitable for Microsoft environments, and Google Cloud is an attractive choice for organizations focused on AI, machine learning, data, and Kubernetes.
