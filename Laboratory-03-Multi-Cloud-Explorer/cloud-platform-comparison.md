## Analysis Questions

### 1. Which cloud provider offers the broadest range of services?

AWS provides an extensive collection of cloud services covering computing, storage, databases, networking, security, analytics, and other technologies. Its large service portfolio makes it useful for organizations with many different technical requirements.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure is the strongest choice for organizations already using Microsoft technologies. Its services can work closely with Windows Server, Microsoft 365, Microsoft Entra ID, and other Microsoft enterprise products.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is particularly strong for artificial intelligence, machine learning, and Kubernetes workloads. Google also provides Google Kubernetes Engine and a range of services designed for data and AI workloads.

### 4. Which cloud platform would you personally choose and why?

I would personally choose Google Cloud because I am interested in artificial intelligence, data processing, and modern cloud-native development. Its services for machine learning and Kubernetes make it an interesting platform for building applications that use current cloud technologies.

## Service Comparison

### Virtual Machines

Each provider offers virtual machines that allow customers to run operating systems and applications without purchasing physical servers.

### Object Storage

Amazon S3, Azure Blob Storage, and Google Cloud Storage provide scalable storage for objects such as files, images, videos, and backups.

### Identity Management

AWS IAM, Microsoft Entra ID, and Cloud IAM provide tools for controlling user and service access to cloud resources.

### SQL Database

Amazon RDS, Azure SQL Database, and Cloud SQL provide managed database solutions that reduce infrastructure administration.

### Kubernetes

Amazon EKS, Azure Kubernetes Service, and Google Kubernetes Engine provide managed Kubernetes environments for containerized applications.
