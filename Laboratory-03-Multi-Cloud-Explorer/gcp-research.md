# Google Cloud Platform (GCP) Research

## Brief Overview

Google Cloud Platform (GCP) is a cloud computing platform provided by Google. It offers computing, storage, networking, databases, artificial intelligence, and machine learning services through Google's global infrastructure.

## Global Infrastructure

GCP operates in multiple regions and zones around the world. Its global network provides high performance, reliability, and low latency for applications and services.

## Cloud Management Console

The Google Cloud Console is a web-based interface used to create, manage, monitor, and configure cloud resources and services.

## Four Core Services

1. **Compute Engine** – Provides virtual machines for running applications.
2. **Cloud Storage** – Provides scalable object storage for data.
3. **Virtual Private Cloud (VPC)** – Provides networking services.
4. **Cloud IAM** – Manages user identities and access permissions.

## Three Advantages

1. **Strong AI and Machine Learning services** – GCP provides advanced AI and ML tools.
2. **Excellent Kubernetes support** – GCP offers powerful container management services.
3. **Global network performance** – Google's infrastructure provides fast and reliable connectivity.

## Typical Enterprise Use Cases

GCP is commonly used for artificial intelligence, machine learning, big data analytics, containerized applications, web services, and scalable cloud applications.
