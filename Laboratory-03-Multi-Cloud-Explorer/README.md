## Mission Overview

This laboratory activity focuses on investigating three major public cloud platforms: Amazon Web Services, Microsoft Azure, and Google Cloud Platform.

The activity examines their infrastructure, management consoles, common services, advantages, and possible business applications. The investigation also includes a Linux environment using KillerCoda to connect traditional server administration with cloud virtual machines.
