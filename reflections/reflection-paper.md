# Reflection Paper

## Reflection on Cloud Computing and Version Control

Technology plays a big role in my everyday life. I often use cloud-based applications like Google Drive, Google Docs, and Gmail for storing files, completing school requirements, and communicating with classmates and teachers. These services make it easier for me to access my work anytime and from any device with an internet connection.
Throughout this course, I learned that cloud computing offers more than online file storage. It provides different service models such as Infrastructure as a Service (IaaS), Platform as a Service (PaaS), and Software as a Service (SaaS), each serving different purposes. I also gained knowledge about cloud deployment models, including Public, Private, Hybrid, and Community Cloud, and how organizations choose the most suitable model based on their needs.
Another valuable lesson I learned is the importance of Git and GitHub in version control. These tools help developers keep track of changes in their projects, organize files efficiently, and collaborate with other team members without losing previous versions of their work. Learning how to create and manage a GitHub repository gave me a better understanding of how software development projects are managed.
Overall, this activity helped me appreciate the value of cloud computing and version control in today's digital world. As an IT student, I know these skills will be useful not only in my studies but also in my future career. I plan to continue improving my knowledge and using these technologies in future projects.
